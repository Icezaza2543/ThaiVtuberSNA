What the connections mean

เส้นเชื่อมแสดงผู้มีปฏิสัมพันธ์สาธารณะที่พบร่วมกันระหว่างช่องในตัวอย่างที่เก็บได้ ไม่ใช่ผู้ชมทั้งหมด และไม่ใช่หลักฐานความสัมพันธ์เชิงเหตุผล

  • Observed overlap: Shared viewers is an intersection count; overlap coefficient divides by the smaller observed set, and Jaccard divides by the union. Temporal snapshots report comment Jaccard separately; the metric menu and profile identify that source. The threshold controls which edges are visible.
  • Time: Slices use dated interaction evidence. Cumulative includes observations up to the selected year; yearly uses that year alone. Available years follow supplied snapshots; missing periods have no invented observations.
  • Identity: Expanded snapshots use date-qualified subscriber and agency evidence; unknown attributes stay unknown. Legacy roster metadata is context only, not historical identity evidence.
  • Centrality: Profile metrics describe structural position in the supplied dataset, not influence or causal migration. The profile overlap list follows the chosen period and includes connections below the graph threshold.
  • Privacy: This public view contains creator metadata and aggregate metrics. It does not expose viewer-level rows or interaction logs.
