Thai VTuber Audience Network (SNA) Architecture

ระบบวิเคราะห์ความสัมพันธ์ของฐานผู้ชมในวงการ VTuber ไทย ออกแบบภายใต้แนวคิด Zero Cloud Cost และ Privacy by Design:

  • Privacy-Preserving Hashing: รหัสประจำตัวผู้ชม (Viewer Channel ID) จะถูกแปลงเป็น HMAC-SHA256(salt, channel_id) ทันทีตั้งแต่จุดรับเข้า ไม่มีการบันทึกข้อความแชต (Zero chat text stored).
  • Local Parquet + DuckDB: เหตุการณ์การรับชมถูกบันทึกลงไฟล์ Parquet บีบอัดแบบ Snappy และใช้ DuckDB รัน Query ค้นหา Intersection ของผู้ชมได้ในระดับมิลลิวินาที.
  • SNA Centrality & Bridge Detection: การคำนวณ Betweenness Centrality ช่วยระบุช่องที่เป็น "สะพานเชื่อม" (Bridge) ระหว่างคอมมูนิตี้และค่ายต่าง ๆ.
  • Simpson Overlap Coefficient: คำนวณ |A ∩ B| / min(|A|, |B|) ช่วยให้เห็นการทับซ้อนของฐานผู้ชมช่องอินดี้ขนาดเล็กกับช่องใหญ่ได้อย่างแม่นยำ.
  • Temporal Audience Dynamics (2020–2026): ไทม์ไลน์แสดงวิวัฒนาการตามหลักฐานปฏิสัมพันธ์จริง (Dated interaction evidence) โดยแยก Audience Interaction Network ออกจาก Content Cohort ชัดเจน และตัดข้อมูลที่ไม่ระบุเวลาออกจากสไลซ์เวลา.
