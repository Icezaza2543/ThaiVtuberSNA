# Luxury editorial UI
Read DESIGN.md for the project's settled palette and typography. This is an
execution technique, not a second competing brand system.
Put discovery first, identity second, supporting evidence quieter but reachable.
Express luxury with space, typography, material contrast and alignment rather
than excessive gold, blur or low-contrast text. Make one memorable composition;
repeat its tokens consistently across results, detail, filters and empty states.
A directory should be denser than the hero. Do not copy an upstream brand.

Use separate Thai-reading, Latin-display and numeric roles when needed. Never
apply Latin tracking to Thai. Check long names, wrapped labels and mixed scripts.
Explicit project font choices override generic prohibitions. Do not generate a
parallel component library or install more packs to revisit a settled palette.

Open the implemented screen in a real browser at mobile/tablet/desktop widths.
Check actual contrast, focus, reduced motion, Thai line height, error/empty states
and useful interactions. A few meaningful screenshots belong outside tracked
source. Never claim browser verification without opening the page.
