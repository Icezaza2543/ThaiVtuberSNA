# ขอแก้ไขข้อมูล ใช้สิทธิ หรือแจ้งการละเมิด

ผู้รับผิดชอบ: **Terasit J.** · **[icezaza.jar@gmail.com](mailto:icezaza.jar@gmail.com)**\
ปรับปรุง: 9 กันยายน 2026

ช่องทางนี้ใช้ติดต่อเรื่องข้อมูลเกี่ยวกับตน สิทธิในผลงาน ความถูกต้องของผล หรือการเผยแพร่ที่กระทบสิทธิ ไม่ต้องเปิดเผยข้อมูลส่วนตัวผ่าน GitHub issue

## ส่งอะไรบ้าง

ใช้หัวข้อ `ThaiVtuberSNA — คำร้องด้านข้อมูล/สิทธิ` และส่งเฉพาะ:

1. URL หน้า/ไฟล์/ผลที่เกี่ยวข้อง หรือ commit หากทราบ
2. สิ่งที่ขอให้ตรวจ: แก้ไข คัดค้าน จำกัดการใช้ ลบ ขอข้อมูล หรือสิทธิในผลงาน
3. ความเกี่ยวข้องของผู้ร้องกับข้อมูล/ผลงาน และคำอธิบายสั้น ๆ
4. ช่องทางตอบกลับ; หลักฐานเพิ่มเติมเท่าที่จำเป็นและเฉพาะเมื่อมีการร้องขออย่างสมเหตุสมผล

**อย่าส่ง** รหัสผ่าน API key รหัสยืนยันตัวตน สำเนาฐานข้อมูลทั้งชุด หรือบัตรประชาชนเต็มใบโดยไม่จำเป็น หากเป็นข้อมูลของบุคคลอื่น ให้ปิดทับส่วนที่ไม่เกี่ยวข้อง การยืนยันสิทธิอาจใช้หลักฐานการควบคุมช่องหรือวิธีที่เปิดเผยข้อมูลน้อยกว่า

## กระบวนการที่ผู้ดูแลต้องดำเนินการ

รับและคัดประเภทคำร้อง → ตรวจตัวตนเท่าที่จำเป็น → จำกัดการเผยแพร่เมื่อมีเหตุสมควร → ตรวจแหล่งข้อมูล/ฐานกฎหมาย → ดำเนินการและตอบพร้อมเหตุผล → ตรวจผลและป้องกันปัญหาเกิดซ้ำ

- การขอเข้าถึงตามมาตรา 30 ที่ไม่มีเหตุปฏิเสธตามกฎหมาย ต้องดำเนินการโดยไม่ชักช้าและไม่เกิน 30 วันนับแต่ได้รับคำขอ; สิทธิประเภทอื่นให้ใช้กรอบเวลาตามบทบัญญัติและกฎที่เกี่ยวข้อง ไม่เหมารวมว่าทุกคำร้องมีเส้นตายเดียวกัน
- หากต้องขอข้อมูลเพิ่ม ต้องแจ้งเหตุผลและขอเฉพาะส่วนจำเป็น ไม่ถือว่าเลื่อนเส้นตายตามกฎหมายได้เอง
- หากปฏิเสธทั้งหมดหรือบางส่วน ต้องระบุเหตุผล ขอบเขต และช่องทางร้องเรียนที่เกี่ยวข้อง ไม่อ้าง “เป็นข้อมูลสาธารณะ” เป็นเหตุปฏิเสธอัตโนมัติ
- การลบต้องพิจารณาสมุดงานส่วนตัว archive ผลรวมที่ต้องสร้างใหม่ และสำเนาภายใต้การควบคุมของโครงการ รวมถึงการนำข้อมูลเดิมกลับเข้าระบบ
- หากต้องเก็บหลักฐานเพื่อหน้าที่กฎหมายหรือสิทธิเรียกร้อง ให้จำกัดเฉพาะส่วนที่จำเป็น ผู้เข้าถึง และระยะเวลา พร้อมแจ้งเหตุผลเท่าที่กฎหมายอนุญาต
- ไม่สัญญาว่าลบสำเนาของบุคคลที่สามทั้งหมดได้ แต่ต้องประเมินและดำเนินขั้นตอนที่กฎหมายกำหนด รวมถึงแจ้งข้อจำกัดแก่ผู้ร้องอย่างตรงไปตรงมา

ขั้นตอนข้างต้นเป็นแนวทางปฏิบัติที่เสนอในชุดเอกสารนี้ **ยังไม่ใช่การรับรองว่ามีระบบคำร้องอัตโนมัติหรือทดสอบการลบครบวงจรแล้ว** ดู [รายการผู้ดำเนินโครงการ](OPERATOR_CHECKLIST.md)

## การแจ้งลิขสิทธิ์และความถูกต้อง

เจ้าของผลงานหรือตัวแทนควรระบุผลงานต้นฉบับ ตำแหน่งที่โครงการใช้ เหตุผลว่ามีสิทธิ และสิ่งที่ต้องการให้ดำเนินการ โครงการต้องตรวจคำร้องอย่างเป็นกลาง ไม่ตัดสินว่าการแจ้งหมายถึงผู้แจ้งถูกหรือผิดทันที และไม่บังคับให้ใช้รูปแบบกฎหมายต่างประเทศกับทุกกรณี

การขอแก้ไขกราฟควรระบุข้อเท็จจริง เช่น ชื่อช่องผิด สังกัดอ้างอิงผิด หรือแหล่งข้อมูลผิด แยกจากความไม่พอใจต่อค่าที่คำนวณตามวิธีที่เปิดเผย

สิทธิร้องเรียนต่อ [สำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล](https://www.pdpc.or.th/) หน่วยงานที่มีอำนาจ หรือศาลยังคงอยู่ ไม่ต้องสละสิทธิหรือยอมรับข้อจำกัดความรับผิดเพื่อให้โครงการพิจารณาคำร้อง

อ้างอิง: [พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล ฉบับเผยแพร่โดยกระทรวงพาณิชย์](https://ictc.ops.moc.go.th/th/content/category/detail/id/142/iid/9152) มาตรา 30–36
