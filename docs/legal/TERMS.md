เอกสารนี้กำหนดขอบเขตการใช้ซอฟต์แวร์ หน้าเว็บ และผลวิเคราะห์ของ ThaiVtuberSNA ผู้ดำเนินการระบบจริงต้องตรวจข้อเท็จจริงและข้อกฎหมายใน [รายการสำหรับผู้ดำเนินโครงการ](OPERATOR_CHECKLIST.md) ก่อนประกาศใช้เป็นเงื่อนไขบริการ การวางไฟล์นี้ใน GitHub เพียงอย่างเดียวไม่พิสูจน์ว่าผู้ใช้ได้ตกลงทำสัญญา และไม่ทำให้การเก็บข้อมูลที่ขาดสิทธิกลายเป็นการเก็บที่ชอบด้วยกฎหมาย

## 1. วัตถุประสงค์และขอบเขต

โครงการใช้ศึกษาความสัมพันธ์จากหลักฐานปฏิสัมพันธ์ที่สังเกตได้ของช่องวีทูบเบอร์ไทย ผลเป็นการวิเคราะห์ของโครงการ ไม่ใช่ข้อมูลรับรองจาก YouTube หรือ Google และไม่ใช่คำตัดสินเรื่องบุคคล ความนิยม ความน่าเชื่อถือ ความสัมพันธ์ส่วนตัว หรือคุณค่าของครีเอเตอร์

ข้อมูลอาจมีความคลาดเคลื่อน ล่าช้า ไม่ครบ หรือเปลี่ยนแปลงเมื่อวิธีเก็บและเกณฑ์เปลี่ยน ผู้ใช้งานต้องอ่านช่วงเวลา แหล่งหลักฐาน เกณฑ์เส้นเชื่อม และข้อจำกัดประกอบ ห้ามอ้างผลที่ยังไม่ครบปีเป็นข้อพิสูจน์การเติบโตหรือลดลงจากปีเต็มโดยไม่มีการปรับวิธีเปรียบเทียบที่เหมาะสม

## 2. สิทธิในซอฟต์แวร์และเนื้อหา

สถานะสิทธิเป็นไปตาม [LICENSE](../../LICENSE): Internal Research / All Rights Reserved สำหรับส่วนที่เจ้าของโครงการมีสิทธิ ไม่อนุญาตแบบเหมารวมให้ดัดแปลง แจกจ่าย ขาย หรือเปิดบริการต่อ การใช้เกินสิทธิที่กฎหมายหรือเงื่อนไขแพลตฟอร์มอนุญาตต้องขออนุญาตเจ้าของสิทธิที่เกี่ยวข้องก่อน

การเผยแพร่ repository ไม่โอนกรรมสิทธิ์ในข้อมูลของครีเอเตอร์ ไม่ให้สิทธิในชื่อช่อง ภาพ ตัวละคร วิดีโอ เสียง เครื่องหมายการค้า หรือผลงานของบุคคลอื่น และไม่จำกัดข้อยกเว้นหรือสิทธิที่กฎหมายรับรอง ผู้ใช้ที่มีสิทธิอ้างอิงควรระบุชื่อโครงการ commit แหล่งต้นทาง ช่วงข้อมูล และวิธีคำนวณ โดยไม่ทำให้เข้าใจว่าได้รับการรับรอง

## 3. การใช้ที่โครงการไม่อนุญาต

- พยายามระบุตัวบุคคลจากข้อมูลนามแฝง หรือจับคู่กับแหล่งอื่นเพื่อเปิดเผยตัวผู้มีปฏิสัมพันธ์
- คุกคาม ประจาน เปิดเผยข้อมูลส่วนตัว ชักชวนให้รุมโจมตี หรือกล่าวหาว่าบุคคลกระทำผิดโดยอาศัยผลกราฟเพียงอย่างเดียว
- อนุมานสุขภาพ ความเชื่อทางศาสนา การเมือง รสนิยมทางเพศ หรือข้อมูลอ่อนไหวอื่นของบุคคล
- ใช้ผลเป็นเกณฑ์อัตโนมัติในการตัดสินใจที่มีผลสำคัญต่อสิทธิ โอกาส หรือบริการของบุคคล
- เผยแพร่ข้อมูลผู้มีปฏิสัมพันธ์รายบุคคล ข้อมูลลับ หรือลิงก์เข้าพื้นที่ส่วนตัว ผ่าน issue, pull request, log, ภาพหน้าจอ หรือไฟล์ส่งออก
- ข้ามระบบควบคุมการเข้าถึง หลีกเลี่ยง quota หรือใช้บัญชี/กุญแจของผู้อื่นโดยไม่ได้รับอนุญาต
- แสดงผลวิเคราะห์เป็นสถิติทางการ หรือทำให้เข้าใจว่า YouTube, Google, ค่าย หรือครีเอเตอร์สนับสนุนโครงการ

ข้อกำหนดนี้ไม่ห้ามการรายงานช่องโหว่โดยสุจริต การวิจารณ์ตามกฎหมาย การแจ้งหน่วยงานรัฐ หรือการใช้สิทธิของเจ้าของข้อมูล

## 4. เงื่อนไขต้นทางยังมีผล

ผู้ดำเนินระบบและผู้ใช้ต้องปฏิบัติตาม [ข้อกำหนด YouTube](https://www.youtube.com/t/terms) และกฎของแหล่งข้อมูลอื่นที่ใช้ หากเปิดฟังก์ชันที่ใช้ YouTube API Services ต้องจัดให้ผู้ใช้ยอมรับข้อกำหนด YouTube และนโยบายที่เกี่ยวข้องตามที่แพลตฟอร์มกำหนดก่อนใช้งาน การติดตั้งโค้ดไม่ใช่หลักฐานว่าได้รับอนุญาตให้เข้าถึงหรือใช้ข้อมูล

ข้อกำหนดของ YouTube จำกัดการเข้าถึงอัตโนมัติและการเก็บข้อมูลระบุตัวบุคคล; ข้อยกเว้นต้องตรงกับเงื่อนไขจริง การอ้างว่าเป็นงานวิจัยหรือใช้ข้อมูลสาธารณะไม่ใช่สิทธิทั่วไปในการทำ scraping ดู [ข้อกำหนดการใช้บริการ](https://www.youtube.com/static?template=terms)

## 5. การแก้ไข ระงับ และคำร้อง

หากมีข้อสงสัยว่าข้อมูลผิดหรือกระทบสิทธิ ให้ติดต่อ [ช่องทางคำร้อง](RIGHTS_REQUESTS.md) ผู้ดูแลควรพิจารณาระงับการเผยแพร่ส่วนที่มีเหตุอันควรระหว่างตรวจ โดยรักษาหลักฐานที่จำเป็นอย่างจำกัดสิทธิ์ การระงับไม่ใช่การยอมรับผิด และไม่ควรใช้เพื่อปฏิเสธคำร้องโดยอัตโนมัติ

อาจแก้ไขหรือนำผลออกเพื่อความถูกต้อง ความปลอดภัย สิทธิบุคคล หรือข้อกฎหมาย ต้องแจ้งผลและเหตุผลแก่ผู้ร้องตามความเหมาะสมและตามหน้าที่กฎหมาย ไม่รับประกันว่าจะเรียกคืนสำเนาใน fork, cache หรือระบบภายนอกได้ทุกชุด

## 6. ขอบเขตการรับประกันและความรับผิด

ภายในขอบเขตที่กฎหมายอนุญาต ซอฟต์แวร์และผลวิเคราะห์จัดให้ตามสภาพและตามที่มีอยู่ ไม่มีการรับประกันความครบถ้วน ความเหมาะสมกับวัตถุประสงค์เฉพาะ ความต่อเนื่องของบริการ หรือผลการตัดสินใจของผู้ใช้ ผู้ใช้ต้องตรวจสอบข้อมูลก่อนใช้และรับผิดชอบต่อการใช้งานของตน

ผู้ดูแลไม่รับผิดชอบความเสียหายทางอ้อมจากการใช้ผลหรือการหยุดให้บริการ **เฉพาะเท่าที่กฎหมายยอมให้จำกัดได้** ไม่มีข้อใดยกเว้นหน้าที่คุ้มครองข้อมูลส่วนบุคคล ความรับผิดจากการจงใจหรือประมาทเลินเล่ออย่างร้ายแรง หรือความรับผิดที่กฎหมายห้ามยกเว้น และไม่มีข้อใดให้ผู้ใช้สละสิทธิร้องเรียน ฟ้องคดี หรือได้รับการเยียวยาตามกฎหมาย

ไม่ได้กำหนดค่าปรับตามอำเภอใจ ข้อชดใช้แบบไม่จำกัด หรือการบังคับให้ร้องเรียนผ่านโครงการเท่านั้น

## 7. กฎหมายและการแก้ไขเงื่อนไข

ฉบับร่างนี้จัดทำโดยมีบริบทประเทศไทย ผู้ดำเนินระบบต้องตรวจเขตอำนาจและกฎหมายที่บังคับใช้จริง รวมถึงกฎหมายที่มีผลข้ามประเทศก่อนเปิดบริการ หากส่วนใดใช้บังคับไม่ได้ ส่วนอื่นใช้ได้เพียงเท่าที่กฎหมายอนุญาต ไม่ลดทอนสิทธิที่บังคับตามกฎหมาย

การแก้ไขสาระสำคัญต้องระบุฉบับและวันที่ แจ้งตามสมควร และขอการยอมรับใหม่เมื่อกฎหมายหรือเงื่อนไขแพลตฟอร์มกำหนด ไม่อ้างว่าการเปลี่ยนไฟล์ย้อนหลังทำให้ผู้ใช้ยินยอมย้อนหลัง
