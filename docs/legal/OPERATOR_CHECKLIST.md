## ประเด็นจากแหล่งทางการ

### ข้อมูลส่วนบุคคล

พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคลครอบคลุมข้อมูลที่ระบุตัวบุคคลได้โดยตรงหรือโดยอ้อมตามมาตรา 6 ต้องพิจารณาความจำเป็น การแจ้ง ฐานกฎหมาย และสิทธิของเจ้าของข้อมูลตามกิจกรรมจริง (มาตรา 22–25 และ 30–37) รวมถึงมาตรา 26 หากเกี่ยวกับข้อมูลอ่อนไหว; ความเป็นสาธารณะและการใช้นามแฝงไม่ใช่ข้อยกเว้นอัตโนมัติ

มาตรา 37 มีหน้าที่แจ้งเหตุละเมิดต่อสำนักงานโดยไม่ชักช้าภายใน 72 ชั่วโมงเท่าที่ทำได้ เว้นแต่ไม่น่ามีความเสี่ยงต่อสิทธิและเสรีภาพ และมีหน้าที่แจ้งเจ้าของข้อมูลเมื่อมีความเสี่ยงสูง ต้องประเมินเงื่อนไขและประกาศที่เกี่ยวข้อง ไม่ใช่รอให้มีคำร้องก่อน

แหล่ง: [ฉบับภาษาไทยที่กระทรวงพาณิชย์เผยแพร่](https://ictc.ops.moc.go.th/th/content/category/detail/id/142/iid/9152) · [คำแปลไม่เป็นทางการจากกระทรวงดิจิทัลฯ](https://www.mdes.go.th/uploads/tinymce/source/%E0%B8%AA%E0%B8%84%E0%B8%AA/Personal%20Data%20Protection%20Act%202019.pdf)

### YouTube: วิธีได้ข้อมูลกับอายุข้อมูลเป็นคนละคำถาม

ข้อกำหนดการใช้บริการจำกัดการเข้าถึงอัตโนมัติและการรวบรวมข้อมูลที่อาจระบุตัวบุคคล การจำกัดไว้ใน private workbook ไม่ทดแทนสิทธิในการได้มาของข้อมูล การที่ repository มี yt-dlp หรือ API library ไม่พิสูจน์ว่ากิจกรรมที่รันได้รับอนุญาต

แหล่ง: [YouTube Terms — Permissions and Restrictions](https://www.youtube.com/static?template=terms)

สำหรับข้อมูลจาก API ต้องตรวจข้อกำหนดการใช้/เก็บ/refresh/delete ตามประเภท นโยบาย derived metrics ที่ตรวจระบุเงื่อนไขเพิ่มเติมสำหรับ use case ที่เข้าเกณฑ์และยอมรับ amendment โดยสถิติ/ผลคำนวณบางอย่างเก็บได้ถึง 36 เดือน แต่ metadata ประเภทอื่นยังอยู่ภายใต้กฎ 30 วัน ไม่ใช่สิทธิให้เก็บ identity ทุกประเภท 36 เดือนหรือย้อนหลังได้ทั้งหมด

แหล่ง: [Developer Policies — III.A, III.E](https://developers.google.com/youtube/terms/developer-policies) · [Additional policies for derived metrics and data storage](https://developers.google.com/youtube/terms/derived-metrics-policy) (หน้าแหล่งระบุปรับปรุง 1 มิถุนายน 2026)

### ลิขสิทธิ์

ข้อยกเว้นงานวิจัย/ศึกษาตามมาตรา 32 มีเงื่อนไข รวมถึงผลต่อการใช้ประโยชน์ตามปกติและสิทธิอันชอบของเจ้าของงาน จึงไม่ควรเหมารวมว่า “เพื่อการศึกษา” อนุญาตให้คัดลอกหรือเผยแพร่ทุกอย่าง ชื่อ/ภาพ/ข้อความและฐานข้อมูลแต่ละส่วนต้องประเมินสิทธิที่เกี่ยวข้อง

แหล่ง: [Copyright Act ฉบับรวมแก้ไขถึงฉบับที่ 5 พ.ศ. 2565 — กรมทรัพย์สินทางปัญญา](https://www.ipthailand.go.th/en/dip-law-2/item/copyright_act2537-2022.html) · [ตัวบทมาตรา 32 ที่กรมทรัพย์สินทางปัญญาเผยแพร่](https://www.ipthailand.go.th/images/781/ActCopyright_update.pdf)
