# Intake

The registry is `data/registry.json`; these files are evidence and collection work products.

- `consolidated/`: stage 1–3 outputs and retained YouTube source material. Use the exact canonical stage paths from `AGENTS.md`, not a glob including partial runs.
- `raw/`: new immutable public captures.
- Dated `*public-profiles*.jsonl`, `*owner*.jsonl`, `*evidence*.jsonl`, directory/hub captures and analytics directories remain at their original paths. Existing evidence and code refer to them.
- `archive/`: historical queues, partial passes and work notes; do not mistake their counts for current coverage.

No raw capture is deleted or rewritten by cleanup. A filename containing a run date is not proof that it is the latest state.
See `docs/data-layout.md` and `reports/current/` for current data locations.
